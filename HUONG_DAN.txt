CÀI MỘT LẦN
Cần Python 3.11+, FFmpeg/FFprobe có libx264/drawtext và libmp3lame. Không cần pip/npm.
Font tiếng Việt kèm sẵn. Python/FFmpeg không kèm ZIP; chưa phải EXE.

Windows 10/11, PowerShell:
  winget install --exact --id Python.Python.3.12
  winget install --exact --id Gyan.FFmpeg
Đóng/mở lại terminal hoặc File Explorer để nhận PATH.
Không có winget: cài Python từ https://www.python.org/downloads/
(chọn Add Python to PATH), FFmpeg từ https://ffmpeg.org/download.html.
Hoặc đặt ffmpeg.exe và ffprobe.exe trong thư mục bin cạnh launch.py.

macOS có Homebrew:
  brew install python ffmpeg
Ubuntu 24.04 / Debian 12 hoặc mới hơn:
  sudo apt update
  sudo apt install python3 ffmpeg

CHẠY
Windows: nhấp đúp START_WINDOWS.bat.
macOS/Linux: trong thư mục giải nén, chạy python3 launch.py.
Hoặc chmod +x START_MAC_LINUX.command rồi ./START_MAC_LINUX.command.
Trình duyệt tự mở http://127.0.0.1:8000. Giữ cửa sổ dòng lệnh mở khi dùng.
Ctrl+C để dừng. Cổng bận: đóng bản cũ hoặc chọn cổng khác:
  PowerShell: $env:PORT='8001'; python launch.py
  macOS/Linux: PORT=8001 python3 launch.py

khi hết quota. Bạn có thể tự đổi về Thủ công.

DỰNG VIDEO 0.7
1. Chọn nguồn: video tối đa 500 MB / 30 phút, MP4 H.264 khuyến nghị.
   Đặt tên dự án. Nhập MP3 tối đa 100 MB hoặc chọn audio đã tạo từ ai33.
   WAV/M4A/FLAC/Ogg được chuẩn hóa sang MP3 khi nhập.
2. Cắt & khớp âm thanh: kéo hai đầu track hoặc nhập giây đầu/cuối.
   Cuối = 0 dùng hết nguồn. Mỗi track hiện giữ một đoạn liên tục.
   Tốc độ hai nguồn độc lập 0,25–4x; âm lượng 0–300%, trễ MP3 theo giây.
   Chọn tiếng gốc, thay bằng MP3 hoặc trộn cả hai. MP3 giữ cao độ.
   Theo MP3: giữ hình cuối nếu thiếu. Theo video: cắt/đệm im lặng MP3.
   Ngắn hơn: cắt phần dư. Có nút khớp tốc độ tính theo thời lượng.
3. Thiết kế: nền một/chuyển hai màu, hòa nền alpha mềm; sáu mẫu khung
   hoặc PNG tĩnh nhập máy (5 MB, 4096 px/cạnh, 8 triệu điểm ảnh).
   Nhấp đúp chữ trên preview để sửa; Ctrl+Enter xác nhận, Escape hủy.
   Kéo hộp để di chuyển, kéo góc dưới phải để chỉnh kích thước.
   Chỉnh X/Y/W/H, font, cỡ, màu, viền, căn trái/giữa/phải/đều hai bên.
   H chữ = 0 tự động. Chữ tràn viền đỏ phải chỉnh vừa mới xuất được.
   Video: X/Y/W/H, zoom 25–400%, xoay -180 đến 180 độ, phủ kín/vừa/kéo giãn.
4. Xuất H.264/AAC: 720x1280, 1080x1920, 2K 1440x2560, 4K 2160x3840;
   nén tiêu chuẩn/chất lượng cao. Tọa độ thiết kế luôn 720x1280.
   Nguồn thấp không có thêm chi tiết khi xuất 4K. Nghe/xem lại file xuất.
Chưa ghép nhiều clip/MP3 hoặc cắt bỏ nhiều đoạn giữa nguồn, chưa tự
nhận lời nói/OCR. Không thêm CTA. Baseline/viền chữ có thể chênh nhẹ
so với preview. Đổi thư mục cần chọn lại nguồn; file cũ không tự chuyển.

TẠO GIỌNG VỚI AI33.PRO
1. Mở tab Âm thanh ai33, nhập AI33 API KEY trong ứng dụng. Chỉ nhập giá
   trị key, không nhập cả chuỗi xi-api-key:. Không gửi key trong chat.
   Không dùng key Gemini/OpenAI. Có thể cấu hình biến máy chủ trước khi
   chạy: REVIEW_AI33_KEY hoặc AI33_API_KEY.
2. Lấy kịch bản tiếng Việt từ tab AI hoặc dán văn bản.
3. Bấm Kiểm tra số dư credit để đọc số dư (tùy chọn). Tạo giọng có thể
   trừ credit ai33, không phải chức năng dịch miễn API.
4. Chọn thư viện và Tải thư viện giọng, tự tải các trang; có bộ lọc/tìm kiếm.
   Chọn giọng hoặc dán voice_id đã có prefix nhà cung cấp. Giọng mẫu
   edge_vi-VN-HoaiMyNeural từ tài liệu; quyền dùng phụ thuộc tài khoản.
5. Chọn tốc độ 0,5–1,5. Mục tùy chọn bổ sung nhận tên file gợi ý và ID
   từ điển phát âm đã có. Từ điển chỉ ảnh hưởng cách đọc.
6. Bấm Tạo audio. Tool nhận task_id, tự kiểm tra mỗi 5 giây. Chờ trạng
   thái done rồi tải/chuẩn hóa MP3. Khi error, tool dừng; không tự tạo
   lại để tránh trừ credit trùng.
7. Nghe và Tải MP3 về máy. Bấm Dùng MP3 này trong video để chọn sang trình dựng.
8. Nếu chờ lâu hoặc reload: nhập key lại, dùng task_id hoặc tải lịch sử
   để lấy lại kết quả. Không cần tạo audio mới. Dừng tự kiểm tra chỉ
   dừng theo dõi, không hủy tác vụ bên ai33. Tự theo dõi tối đa 15 phút
   mỗi đợt; có thể kiểm tra lại tác vụ cũ.

NÂNG CẤP 0.17.3 — SỬA TÁCH GIỌNG AI (DEMUCS)
- Mục 🎵 Âm thanh gốc có nút "⬇ Cài Demucs tự động". Bấm một lần, chờ vài phút; lần đầu tải khoảng 1–3 GB.
  App cài vào thư mục .local/demucs-env của ứng dụng, không đụng tới Python của máy.
